# Test fonts

The fonts in this directory are used by the crate's tests only; they are not
part of the library. They were copied unmodified from the test assets of the
Avalonia repository (`tests/Avalonia.Skia.UnitTests/Fonts` and
`tests/Avalonia.RenderTests/Assets`). Each font carries its own licence.
