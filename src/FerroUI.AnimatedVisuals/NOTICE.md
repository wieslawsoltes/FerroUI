# Animated visuals

This crate is written for FerroUI. It reads the Lottie (Bodymovin) JSON format, whose structure is
described by the [Lottie specification](https://lottie.github.io/). No code of a Lottie player is
copied into it.

The API it will serve, `AnimatedVisualPlayer`, `AnimatedIcon` and `IAnimatedVisualSource`, follows
[microsoft-ui-xaml](https://github.com/microsoft/microsoft-ui-xaml) (MIT, Copyright (c) Microsoft
Corporation).
