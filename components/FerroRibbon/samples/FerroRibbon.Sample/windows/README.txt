FerroRibbon Gallery for Windows

Extract the archive and run FerroRibbon.exe.

The gallery uses Windows system ICU from Windows 10 version 1903 or later
and the x64 Microsoft Visual C++ v14 Redistributable. Download the runtime
from Microsoft's supported redistributable page if it is needed.

https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

The licenses directory contains the application and dependency notices.
The package manifest records the source and framework revisions and the
SHA-256 hash of each packaged file.
