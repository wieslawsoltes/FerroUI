# Feature coverage

This is an implementation inventory, not a claim of complete Figma parity. “UI” means there is an editing path in this application. “Structured” means the document model and renderer support the data but editing requires the validated layer/collection JSON dialog or a client using the core API. Actual build and interaction evidence is recorded separately in [VALIDATION.md](VALIDATION.md).

## Features outside this implementation

### Rendering and authoring limits

Normal artwork remains vector geometry, brushes, pens and text submitted through FerroUI. Background blur, pixel masks and fractional pass-through replacement are bounded raster operations: each padded surface supports at most 2048 pixels per dimension and 4 million pixels, with 32 MiB of retained backdrop cache, 128 MiB of conservative working reservations and eight nested filters. Canvas sampling follows zoom and display scaling; PNG sampling follows export resolution. Panning reuses cached filtered output. A declined blur increments explicit renderer diagnostics and renders remaining layer content. Declined pixel masks fail closed instead of revealing masked artwork. A declined fractional pass-through replacement retains once-only opacity but reports its unavailable backdrop behavior.

The public `DrawingContext::try_push_compositing_layer` capability records/replays isolated blend and opacity scopes through FerroUI. Skia and Vello implement it; an unsupported backend returns `None` without changing the state stack. `ImmutableLuminanceToAlphaEffect` is a public immutable effect with immediate and recorded pixel tests in both backends. Group opacity is applied to completed overlapping children once. Background replacement operates on premultiplied pixels within document isolation, so it does not copy the editor canvas background into a transparent export.

The native Effects editor supports drop shadow, inner shadow, layer blur and background blur. Radius accepts finite values from 0 to 10,000; shadow offsets/spread accept finite signed values within ±1,000,000. RGB entry accepts three or six hexadecimal digits and preserves the existing alpha. Opacity accepts 0–100% and is quantized once to the document's 8-bit alpha. Numeric Up/Down commits a step of 1, Shift uses 10 and Alt uses 0.1. Enter or focus loss commits, while Escape discards the draft; active IME composition keeps its native input ownership. Native inspector drafts join the text-edit lifecycle boundary: page hide, window close, save and export commit confirmed values before serialization. Invalid drafts remain dirty and retain their validation; Escape discards them. IME detachment preserves confirmed Unicode and range styling. Invalid batches and unchanged fields leave the document, redo state and styles intact. A changed layer detaches its effect-style binding and records an explicit effects override.

Effect order is preserved in the portable document. Within each shadow kind, the first listed shadow paints above later shadows through both rounded-rectangle and general geometry paths. Drop shadows precede the layer body; leaf/Boolean inner shadows paint after fills and before strokes, while container inner shadows paint above their compound content. This staged composition is the implemented effect behavior; it does not establish arbitrary filter-graph or full Figma effects parity. Authoring bounds and background-blur allocation limits are separate checks.

Vector-network regions are explicit topological contours. Branching edges may exist without fills, and implicit fill-closing edges can remain unstroked. Stable IDs survive splitting, movement and undo. Geometry normalization preserves world placement, including reflected or sheared parents. **Fill all closed regions** prepares certified crossings and discovers bounded faces of the resulting line/cubic network, including nested holes and shared boundaries. Untouched edges retain their original values; split edges retain exact Bézier subdivision geometry and stable first-subedge IDs. It excludes open branches from fill contours, keeps matching region IDs and commits one scoped edit. When inherited regions need a layer fill and the layer has none, the command adds one neutral solid fill; faces with explicit region paint overrides retain those overrides. Each region either inherits the layer fill stack or owns an independent ordered stack; an explicit empty stack clears that region. Native rendering and supported SVG/XAML export preserve region replacement and draw the shared edge graph once.

The low-level face-discovery API remains strict. Native authoring first prepares line/line, line/cubic, certified cubic/cubic and self-crossing intersections on a private copy, splits them into shared vertices and certifies the resulting embedding. Overlaps, tangencies, nearby distinct roots that cannot be separated, coincident outgoing tangents and uncertified orientation decline atomically; close roots are never tolerance-welded into one junction. Preflight errors, exhausted IDs and repeated unchanged calls preserve the document and undo/redo state. Limits are 32,768 edges, one million geometric work units and subdivision depth 40; these bounds do not imply linear-time handling of adversarial overlapping curves. Bucket hover prepares a checked `NetworkFaceMap` when geometry changes and reuses its bounds index and exact curves. A drag tests the segment between pointer events, batches newly visited faces and captures its paint stack and Shift-clear mode at press time. Escape and lost capture cancel its owned transaction; save/page-hide finish it once, while background autosave waits until the gesture ends. See [vector faces and bucket authoring](VECTOR_FACES.md) for geometry, identity and failure contracts.

[Angular paints](ANGULAR_PAINTS.md) use FerroUI's public `ImmutableConicGradientBrush` for artwork, strokes, masks and PNG rendering. Centers are relative to each brush target; angles run clockwise from the upward ray. The fill and local-style editors preserve complete stop stacks when changing gradient types. XAML emits native `ConicGradientBrush` properties. SVG reports an approximation of at most 1,024 vector sectors per paint; complex aligned outlines, arrowheads and shaped-text paint bounds can differ from native rendering. CSS preserves authored hard-stop boundaries and adds at most 1,024 stops where straight native RGBA interpolation differs from CSS premultiplied interpolation; long stop lists share a coarser sampling budget. A one-stop CSS paint becomes a constant color. These exports retain their existing format subsets, and SVG is not an editable angular-gradient round trip.

Flattening exports actual FerroUI geometry through `Geometry::try_get_path_data`, retaining curves and fill rules instead of sampling them or rebuilding glyphs from font names. `TextLayout::try_build_geometry` verifies that every shaped run has complete monochrome contours, including glyph positioning offsets and decorations. A backend without that capability declines conversion. Color, bitmap and SVG-font artwork is rejected conservatively even when a font supplies partial fallback outlines.

A supported single shape, text layer or Boolean result becomes an editable path in place, keeping its ID, parent, stack position, affine transform, paints, effects, interaction and layout-child settings. Homogeneous opaque adjacent siblings with the same parent or suitable groups can union only when their appearance remains representable by one path. Multi-root auto-layout selections and group-owned paints, clipping or layout are unsupported. Masks, component masters, instances and owned instance descendants, independent child compositing/strokes, incompatible paints and references to descendants that would be removed cause rejection before mutation. Per-run text colors, translucent text paints and gradient/image text remain outside this conversion. Translucent glyphs and decorations can accumulate alpha where they overlap; one filled vector path cannot retain those independent paint regions. Whole-layer opacity on otherwise opaque text remains supported. Already editable vectors are no-ops. Unsupported or unchanged operations preserve the allocator, selection, revision, history and redo state.

Rounded box shadows and general path shadows have different interior masking. A box-shadow layer without a fully opaque solid or gradient fill therefore remains unchanged when flattened. Outward shadow spread on a box with a square corner also remains unchanged: the vector offset would round that corner. This covers positive drop-shadow spread and negative inner-shadow spread. A container that combines a visible inner shadow with a visible stroke remains unchanged because those effects paint in a different order on a path. Whole-layer opacity does not change the opaque-fill check; it still applies once to the completed layer.

Local style definitions keep effective values on nodes so portable documents remain self-contained. Editing a definition updates valid bindings across pages, including hidden and locked layers, without creating instance overrides. Explicit apply/detach commands skip effective locks and incompatible layer types. A manually changed bound property detaches only its corresponding style, while a pure move keeps every binding. Imported bindings whose effective values already differ from the prior definition detach on value propagation instead of losing the customized appearance. Renaming alone changes only metadata; deleting a definition clears links while retaining all effective values. Native style fields use the same draft, validation, Escape and lifecycle-save behavior as other inspector editors.

Component variant changes match source identity, then layer name/kind and sibling occurrence. Matching materialized layer IDs and explicit overrides survive a switch. Exposed property controls display effective direct descendant overrides; setting or resetting that property clears its corresponding direct flags. Component synchronization can affect dependent instances and layout, so it still uses full document history snapshots. The performance benchmark reports this cost separately from scoped single-node editing.

Scoped canvas edits use an editor change feed to refresh affected render data and ancestor bounds. Camera frames retain prepared geometry, text and paints. With at least 32 prepared roots, a balanced bounding-volume hierarchy uses conservative world subtree bounds, including overflow and effect extents, to select root paint candidates. Spatial query output is restored to document stacking order. Identical viewport queries reuse the retained candidate buffer, bounds changes refit affected branches, and a viewport containing the entire root bounds reuses the existing ordered root list. Smaller root sets use the direct traversal path.

Structural, component, variable and layout transactions retain full preparation; missing history or unusual dependency sets also fall back to a complete refresh. Root signatures still hash root IDs, visible descendants still require drawing, and wide ancestor bounds still inspect siblings. Overlapping root bounds can produce a large candidate set. `rootBoundsTests`, `rootCandidates` and `rootQueryReused` expose broad-phase work separately from prepared-node/visual and layer-projection counters. A one-leaf preparation result or a small candidate set is not a constant-time full frame or an FPS measurement.

The layer sidebar consumes the same complete change feed to reuse unchanged row data on scoped edits, avoiding a fresh name and row allocation for every displayed layer. Page/assets/search/expansion changes, incomplete history and structural edits retain conservative projection. Expanded-set equality may still visit expanded IDs; scoped history still copies document metadata such as page root IDs. These remaining costs are separate from node snapshots, row projection and render preparation.

Grid placement is zero-based in the serialized model and one-based in native fields; empty/Auto leaves a coordinate unspecified. Pinned children reserve cells before automatic children, while hidden and absolute children do not occupy tracks. Invalid spans and occupied-cell collisions are rejected atomically by authoring commands. Connected groups of overlapping row spans use equal-height tracks for stable repeated Hug/Fill layout. Existing grids without nondefault placement metadata retain their earlier layout path.

Canvas layout dragging retains sibling identity/geometry and the original layout while the pointer is captured. A balanced insertion-edge index chooses a target without cloning the document or reflowing on every pointer event. The preview writes no document, revision or history state. Release validates that the original document/session still owns the selection, then validates and commits one candidate reorder/reflow. Returning to the original layout rectangle, Escape, capture loss, tool/camera changes or a stale session discards the preview. The first Undo during a held preview cancels it; the next Undo acts on the preceding committed edit.

The transfer session normalizes selected roots, preserves their original visual order and converts world transforms into the destination parent without flattening geometry. Entering an automatic layout resets placement pins only on the transferred roots; unselected hidden/absolute/pinned siblings retain their metadata. Empty layout frames accept insertion, ordinary free movement hands off only on reaching a valid destination, and leaving the destination can restore the original preview. A session carries opaque transaction ownership in addition to revision/selection checks, so replacing an editor at the same revision or starting another draft cannot let a stale gesture commit or cancel someone else's work. Explicit empty-cell pinning remains a placement-dialog operation.

### SVG import limits

The importer accepts up to 16 MiB of SVG source and validates the resulting document before adding it. An error leaves the document and history unchanged. Editable local `clipPath` and alpha/luminance `mask` definitions support object/user units, affine transforms, nested local references and inherited definitions; cyclic or foreign-namespace references fail atomically. Unsupported visual constructs are rejected explicitly: filters, pattern paints, markers, nonzero dash offset, non-scaling strokes, repeat/reflect gradients, offset-focus or unsupported elliptical radial gradients, positioned `tspan`, text paths, text-length constraints, per-character rotations, vertical/explicit RTL text and complex CSS selectors. SVG linear-RGB luminance is rejected rather than being misrepresented as the implemented sRGB mask conversion. Rectangular clipping for SVG viewports is supported. Script/event content, DTDs, external resources, reference cycles and duplicate SVG IDs are rejected. Text remains editable; the renderer uses actual FerroUI baseline/anchor metrics, while core text selection bounds are estimated.

### Other products and services

The source does not contain Figma's multiplayer service, accounts, team permissions, live presence, audio calls, plugin/widget runtime, community marketplace, AI services, billing, cloud libraries, full proprietary file interoperability or the separate FigJam/Slides/Sites/Make/Draw product feature sets. A portable design download is the sharing mechanism. Local comments and components do not imply those server products.
