# NOTICE

This crate is a port of the AppWithoutLifetime sample of the upstream project
(MIT; see the `NOTICE.md` at the root of the repository).

- The markup documents `App.xaml`, `MainWindow.xaml` and `Sub.xaml` are converted from the
  upstream documents by `scripts/convert_catalog_xaml.py`; the conversion changes names only
  (the name of the upstream project in the texts of the windows is the name of this project).
- The Rust sources are ports of the upstream C# sources, file by file.
