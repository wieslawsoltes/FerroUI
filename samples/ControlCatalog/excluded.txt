# Documents of the sample that do not load yet: `<document> | <reason>` (see `build.rs`); the
# generated tests of a listed document are ignored with the reason. `page: <reason>` lists a
# document that loads but whose class does not construct or show yet.
#
#   missing: <types>         framework types that are not ported; the class of the document is not declared
#   gap <id>: <text>         a gap of the framework; reproduced in tests/gaps*.rs
#   code-behind: <text>      the class of the document needs framework API that does not exist
#   pending: <text>          the class of the document is not ported yet
#   harness: <text>          the document loads in the application but not under the unit test application
#
# Keep the sections; lines are sorted by path within a section. `GAPS.md` explains each open entry.
